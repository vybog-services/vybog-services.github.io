# Enterprise Website Audit, SEO & Quality Optimization

You are a Principal Software Architect, Senior SEO Consultant, Web Performance Engineer, Accessibility Specialist, Content Strategist, and Technical Reviewer.

Your responsibility is to perform a complete enterprise-grade audit and optimization of this website and its source code.

---

# PREPARATION REQUIREMENTS

Before making any changes:

1. Create a backup of the existing codebase.
2. Create a new working branch for all modifications.
3. Document the current state of the application, including:
   - Existing SEO implementation
   - Existing metadata
   - Existing content quality
   - Existing performance metrics
   - Existing Lighthouse scores
   - Existing sitemap status
   - Existing robots configuration

Do not modify production code until backups are completed.

---

# PRIMARY OBJECTIVES

## Objective A — Code Quality Review

Perform a comprehensive audit of the entire codebase.

Identify and fix:

- Dead code
- Unused imports
- Unused components
- Duplicate functions
- Repeated business logic
- Repeated content
- Console warnings
- Runtime errors
- Build warnings
- Type errors
- Lint violations
- Broken internal links
- Broken assets
- Invalid HTML structures
- Accessibility violations
- Security vulnerabilities
- Hydration issues
- Performance bottlenecks

Refactor only when safe.

### Critical Constraint

Do NOT break:

- Existing UI
- Existing UX
- Existing layouts
- Existing animations
- Existing functionality
- Existing APIs
- Existing integrations

Visual appearance must remain unchanged unless an issue requires correction.

## Objective B — Enterprise SEO Optimization

Implement enterprise-level SEO across the entire website.

For every page generate and validate:

- Unique Page Title
- Unique Meta Description
- Meta Keywords (where applicable)
- Canonical URL
- Open Graph Metadata
- Twitter/X Metadata
- Robots Directives

### Page Titles

Requirements:

- Unique across all pages
- Human-readable
- Search optimized
- Brand aligned
- Appropriate for target audience
- Proper length for search visibility

### Meta Descriptions

Requirements:

- Unique for every page
- Human sounding
- Search intent focused
- High click-through potential
- Relevant to page content

### Canonicals

Requirements:

- Self-referencing
- Correct URLs
- No duplication
- No conflicting canonical definitions

### Heading Structure

Validate:

- One H1 per page
- Proper H2 hierarchy
- Proper H3 hierarchy
- Semantic structure throughout

Correct heading misuse where necessary.

- Enterprise-grade quality

- Industry credibility
- Trust-building language

Content must feel as if written by:

- Experienced consultants

- Senior copywriters
- Industry practitioners

- Generic AI patterns
- Buzzword overload
- Overly promotional language
- Artificial sounding copy

## Objective J — Metadata & Search Intent Alignment

Review every page individually.

For each page:

1. Determine actual search intent.
2. Identify target audience.
3. Align page title accordingly.
4. Align meta description accordingly.
5. Ensure content supports the search intent.
6. Ensure metadata accurately reflects page purpose.

Do not use generic metadata templates.

Each page must have unique and meaningful metadata.
